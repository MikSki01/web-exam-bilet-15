# Білет №15 — Збереження даних у localStorage

Екзаменаційна практична робота з дисципліни «Веб-дизайн та веб-програмування».
Автор: Скороход Михайло Євгенійович, група МІТ-21.

## Завдання
Вхідні дані:
```js
const settings = { theme: 'dark', fontSize: 18 };
```
1. Зберегти об'єкт у `localStorage` під ключем `examSettings`.
2. Прочитати значення та відновити об'єкт. Якщо ключ відсутній — використати `{ theme: 'light', fontSize: 16 }`.
3. Вивести значення `theme` і `fontSize` відновлених налаштувань.

**Очікуваний результат:** після збереження виводяться `dark` і `18`; за відсутності ключа — `light` і `16`.

## Реалізація
- `saveSettings()` — `localStorage.setItem('examSettings', JSON.stringify(settings))`.
- `loadSettings()` — читає ключ; якщо `null` або некоректний JSON, повертає значення за замовчуванням `{ theme: 'light', fontSize: 16 }`.
- `render()` — виводить `theme` і `fontSize` та наочно застосовує тему й розмір шрифту до сторінки.
- Усі операції зі сховищем обгорнуто в `try/catch`.

## Запуск
Відкрити `index.html` у браузері або через локальний сервер:
```bash
python3 -m http.server 8000
# http://localhost:8000
```
Кнопки: **Зберегти** → збереже dark/18; **Прочитати** → відновить значення; **Очистити ключ** → покаже значення за замовчуванням light/16.
